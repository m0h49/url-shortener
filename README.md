# URL Shortener

Короткое описание проекта.

## Stack
- React + TypeScript
- Node.js + Express
- PostgreSQL
- Redis
- Docker Compose

## Features
- создание коротких URL
- redirect
- подсчёт переходов
- статистика
- Redis cache

## Run

docker compose up --build

Frontend:
http://localhost:5173

Backend:
http://localhost:33000
